# GalaxySol.CS 🌌

[![License: MIT](https://shields.io)](https://opensource.org)
![.NET Version](https://shields.io)

The ultimate, all-inclusive .NET 10 ecosystem and swiss-army knife framework built for absolute development freedom. It aggregates reusable modules, custom API wrappers, and foundational infrastructure to solve any development task without code clutter.

---

## 📐 7-Layer Architecture

The solution workspace is organized into seven conceptual layers. On the file system and GitHub, they are isolated into clean, non-numbered root directories:

* 📦 **`Core`** — Low-level, pure in-memory foundation containing primitive types, strict data validation mechanics (`Guard`), and global system extension methods.
* 🛠️ **`Helpers`** — Everyday utility toolkits, including text transformers, advanced date formatters, unified JSON wrappers, and high-performance CSV parsers.
* 🧠 **`Algorithms`** — The analytical brain of the ecosystem, hosting custom data structures, sorting algorithms, graph/tree traversals, and cryptographic engines.
* ⚙️ **`Infrastructure`** — Deep OS integration and environment management, covering configuration mapping, native process execution (like FFmpeg engines), logging, and system hardware metrics.
* 🚀 **`Services`** — Heavy-duty business logic and external integrations, including video/audio processing pipelines, web scraping services, and third-party API clients (e.g., NovaPoshta).
* 🖥️ **`Apps`** — Ready-to-run executable utilities, internal CLI automation tools, rapid project scaffolders, and background workers.
* 🧪 **`Tests`** — Comprehensive automated unit and integration testing environment ensuring cross-layer stability.
